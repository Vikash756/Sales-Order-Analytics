# Sales & Order Management Analytics System

## 📌 Project Overview

The **Sales & Order Management Analytics System** is an end-to-end data analytics project built to analyze customer, product, order, payment, and sales data.

The project uses **PostgreSQL for data storage and SQL analysis** and **Power BI for interactive dashboarding**. It demonstrates practical skills in database design, SQL analytics, data quality validation, business analysis, advanced SQL, query optimization, and data visualization.

---

## 🎯 Project Objectives

- Design a relational sales database using PostgreSQL
- Import and validate multiple CSV datasets
- Perform data quality checks
- Analyze sales, customers, products, categories, cities, and order statuses
- Apply advanced SQL concepts such as subqueries, CTEs, CASE, and window functions
- Create reusable SQL views
- Improve query performance using indexes
- Build an interactive Power BI dashboard
- Present business KPIs and actionable sales insights

## 🗃️ Database Design

The PostgreSQL database contains five main tables:

### 1. Customers
Stores customer information such as:

- Customer ID
- Name
- Email
- City
- Signup Date

### 2. Products
Stores product information:

- Product ID
- Product Name
- Category
- Price
- Stock

### 3. Orders
Stores order-level information:

- Order ID
- Customer ID
- Order Date
- Status
- Total Amount

### 4. Order Items
Stores individual products included in each order:

- Order Item ID
- Order ID
- Product ID
- Quantity
- Unit Price

### 5. Payments
Stores payment information:

- Payment ID
- Order ID
- Payment Date
- Amount
- Payment Status

### Relationships

```text
Customers
    │
    │ 1 : Many
    ▼
Orders
    │
    ├──────────────► Payments
    │
    │ 1 : Many
    ▼
Order Items
    │
    │ Many : 1
    ▼
Products
```

## 🧠 Advanced SQL

The project also demonstrates advanced SQL techniques:

### Subqueries
Used to identify orders and customers performing above average.

### CTEs
Used to make multi-step customer revenue analysis easier to read and maintain.

### CASE Statements
Used to classify orders into:

- High Value
- Medium Value

The project uses:

- `RANK()`
- `ROW_NUMBER()`

## 🚀 How to Run the Project

### Step 1 — Set up PostgreSQL

Install PostgreSQL and pgAdmin 4.

Create a database:

```sql
CREATE DATABASE sales_order_analytics;
```

### Step 2 — Create Tables

Run:

```text
SQL/01_table_creation.sql
```

### Step 3 — Import CSV Data

Import the five CSV files from the `Data/` folder into their respective PostgreSQL tables.

### Step 4 — Validate Data

Run:

```text
SQL/02_data_quality.sql
```

### Step 5 — Perform Business Analysis

Run:

```text
SQL/03_business_analysis.sql
```

### Step 6 — Run Advanced SQL

Run:

```text
SQL/04_advanced_sql.sql
```

### Step 7 — Create the View

Run:

```text
SQL/05_views.sql
```

### Step 8 — Create Indexes and Check Performance

Run:

```text
SQL/06_indexes.sql
```

### Step 9 — Open Power BI

Connect Power BI to the PostgreSQL database and load the required tables/view.

Open:

```text
PowerBI/Sales_Order_Analytics.pbix
```
